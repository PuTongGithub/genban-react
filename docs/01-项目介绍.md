# 项目介绍

## 概述

genban-react 是一个基于 React 19 的 AI 聊天助手前端应用，提供流式对话、模型切换、会话管理等功能。

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| React | 19.2.0 | UI 框架 |
| TypeScript | 5.9.3 | 类型安全 |
| Vite | 7.3.1 | 构建工具 |
| ESLint | 9.39.1 | 代码规范 |

## 核心功能

- **流式对话**：支持 SSE 流式响应，实时显示 AI 回复
- **模型切换**：动态选择不同的 AI 模型
- **会话管理**：支持新建会话，保持对话上下文
- **思考过程展示**：可折叠显示 AI 的推理过程

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 项目结构

```
src/
├── api/          # API 服务层
├── components/   # UI 组件
├── constants/    # 常量定义
├── hooks/        # 自定义 Hooks
├── types/        # TypeScript 类型
├── App.tsx       # 根组件
└── main.tsx      # 入口文件
```

## 设计原则

1. **单一职责**：每个模块只负责一个功能
2. **关注点分离**：UI、逻辑、数据层分离
3. **高内聚低耦合**：模块内部紧密相关，模块间依赖最小化
