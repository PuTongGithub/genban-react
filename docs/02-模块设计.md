# 模块设计

```

│                    UI Layer                         │

│  └────┬─────┘ └────┬─────┘ └────┬─────┘ └───┬────┘ │
│       └────────────┴────────────┴──────────┘       │
│                         │                           │
│              ┌──────────┴──────────┐               │
│              │   ChatAssistant     │               │
│              │   (主组件/容器)      │               │
│              └──────────┬──────────┘               │
└─────────────────────────┼───────────────────────────┘
                          │
┌─────────────────────────┼───────────────────────────┐
│                   Logic Layer                       │
│              ┌──────────┴──────────┐               │
│              │  Custom Hooks       │               │
│              │  ┌────────────────┐ │               │
│              │  │   useChat      │ │               │
│              │  │   useModels    │ │               │
│              │  └────────────────┘ │               │
│              └──────────┬──────────┘               │
└─────────────────────────┼───────────────────────────┘
                          │

│              ┌──────────┴──────────┐               │

│              └─────────────────────┘               │
└─────────────────────────────────────────────────────┘
```

## 文件与模块对应关系

### API 层 (`src/api/`)

| 文件 | 职责 | 导出 |
|------|------|------|
| `chatApi.ts` | 封装所有后端 API 调用 | `chatApi` 实例 |
| `index.ts` | 统一导出 | - |

### 组件层 (`src/components/ChatAssistant/`)

| 文件 | 职责 | Props |
|------|------|-------|
| `ChatAssistant.tsx` | 主容器组件，组合所有子组件 | 无 |
| `ChatHeader.tsx` | 头部：标题、模型选择、新建对话 | `models`, `selectedModel`, `isLoading`, `onModelChange`, `onNewChat` |
| `MessageList.tsx` | 消息列表：渲染消息、空状态、自动滚动 | `messages`, `isLoading`, `isReasoningExpanded`, `onToggleReasoning` |
| `MessageItem.tsx` | 单条消息：用户/助手消息、思考过程 | `message`, `isLoading`, `isLast`, `isReasoningExpanded`, `onToggleReasoning` |
| `ChatInput.tsx` | 输入区域：文本框、发送按钮 | `value`, `isLoading`, `disabled`, `onChange`, `onSend` |
| `index.ts` | 统一导出所有组件 | - |

### Hooks 层 (`src/hooks/`)

| 文件 | 职责 | 返回值 |
|------|------|--------|
| `useModels.ts` | 管理模型列表和选中状态 | `{ models, selectedModel, setSelectedModel, isLoading, refetch }` |
| `useChat.ts` | 管理聊天状态和操作 | `{ sessionId, messages, isLoading, sendMessage, clearMessages, createSession }` |
| `index.ts` | 统一导出 | - |

### 类型层 (`src/types/`)

| 文件 | 职责 | 导出类型 |
|------|------|----------|
| `message.ts` | 消息相关类型定义 | `Message`, `StreamData`, `TalkRequest` |
| `index.ts` | 统一导出 | - |

### 常量层 (`src/constants/`)

| 文件 | 职责 | 导出 |
|------|------|------|
| `api.ts` | API 相关常量 | `API_BASE` |
| `index.ts` | 统一导出 | - |

## 数据流

```
用户输入
    │
    ▼
ChatInput (onChange)
    │
    ▼
ChatAssistant (状态管理)
    │
    ▼
useChat.sendMessage()
    │
    ▼
chatApi.sendMessage()
    │
    ▼
Backend API (POST /api/talk)
    │
    ▼
SSE Stream Response
    │
    ▼
useChat (更新 messages)
    │
    ▼
MessageList (重新渲染)
```

## 依赖关系

```
App.tsx
  └── ChatAssistant
        ├── useModels (Hook)
        │     └── chatApi.getModels()
        ├── useChat (Hook)
        │     └── chatApi.createSession()
        │     └── chatApi.sendMessage()
        ├── ChatHeader
        ├── MessageList
        │     └── MessageItem (多个)
        └── ChatInput
```
