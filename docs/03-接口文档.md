# 接口文档

## 基础信息

- **Base URL**: `/api`
- **数据格式**: JSON
- **字符编码**: UTF-8

---

## 接口列表

### 1. 获取模型列表

获取可用的 AI 模型列表。

**请求**

```
GET /api/get_models
```

**响应**

```json
["model-1", "model-2", "model-3"]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| - | `string[]` | 模型名称数组 |

---

### 2. 创建新会话

创建一个新的对话会话，返回会话 ID。

**请求**

```
GET /api/new_session
```

**响应**

```json
"session-uuid-string"
```

| 字段 | 类型 | 说明 |
|------|------|------|
| - | `string` | 会话 ID |

---

### 3. 发送消息（流式）

发送用户消息并获取 AI 流式响应。

**请求**

```
POST /api/talk
Content-Type: application/json
```

**请求体**

```json
{
  "sessionId": "session-uuid-string",
  "userInput": "你好，请介绍一下自己",
  "model": "model-1"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| sessionId | `string` | 是 | 会话 ID |
| userInput | `string` | 是 | 用户输入内容 |
| model | `string` | 是 | 选择的模型名称 |

**响应**

SSE (Server-Sent Events) 流式响应：

```
data: {"role": "assistant", "content": "你", "reasoning_content": ""}

data: {"role": "assistant", "content": "好", "reasoning_content": "让我思考一下..."}

data: {"role": "assistant", "content": "！", "reasoning_content": ""}

data: [DONE]
```

**数据格式**

| 字段 | 类型 | 说明 |
|------|------|------|
| role | `string` | 角色，固定为 `"assistant"` |
| content | `string` | 回复内容片段（需累加） |
| reasoning_content | `string` | 思考过程片段（需累加） |

**错误响应**

```json
data: {"error": "错误信息"}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| error | `string` | 错误描述 |

---

## TypeScript 类型定义

```typescript
// 消息类型
interface Message {
  role: 'user' | 'assistant';
  content: string;
  reasoningContent?: string;
}

// 流式数据类型
interface StreamData {
  role: 'user' | 'assistant';
  content: string;
  reasoning_content: string;
}

// 发送消息请求类型
interface TalkRequest {
  sessionId: string;
  userInput: string;
  model: string;
}
```

---

## 错误处理

| HTTP 状态码 | 说明 |
|-------------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 500 | 服务器内部错误 |

流式响应中的错误通过 `data: {"error": "..."}` 格式返回。

---

## 使用示例

### 发送消息

```typescript
import { chatApi } from './api';

// 发送消息并处理流式响应
await chatApi.sendMessage(
  {
    sessionId: 'your-session-id',
    userInput: '你好',
    model: 'model-1',
  },
  // 流式数据回调
  (data) => {
    console.log('收到数据:', data.content);
  },
  // 错误回调
  (error) => {
    console.error('发生错误:', error);
  }
);
```
